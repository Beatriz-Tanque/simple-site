Projetos

Este projeto representa meu primeiro desenvolvimento na área de programação web. Foi criado com o objetivo de aplicar, na prática, conceitos fundamentais de HTML e CSS, além de compreender a estrutura e organização de uma página web.

Durante o desenvolvimento, trabalhei na construção do layout, estilização dos elementos e adaptação do site para diferentes tamanhos de tela, buscando uma experiência de navegação consistente.

Este projeto marca o início da minha trajetória como desenvolvedora, demonstrando meu comprometimento com o aprendizado contínuo e a evolução técnica por meio da prática.

Além disso, este trabalho serviu como base para consolidar meus conhecimentos iniciais e identificar pontos de melhoria, contribuindo para o desenvolvimento de projetos futuros mais completos e bem estruturados.
