Site Portfólio Pessoal

Site desenvolvido em HTML5 e CSS3 puro, sem frameworks, hospedado no GitHub Pages. Trabalhei na estrutura de múltiplas páginas com navegação compartilhada, layout responsivo com Flexbox e estilização de cards de contato.

Foi meu primeiro projeto de desenvolvimento web, e serviu de base para entender estrutura de página, organização de arquivos e publicação de um site estático.

Reconhecimento de Rede com Nmap

Projeto prático de segurança da informação, feito em Kali Linux rodando em VirtualBox. Rodei scans de reconhecimento contra o scanme.nmap.org (servidor autorizado para prática) usando detecção de versão de serviço e scripts padrão do Nmap (nmap -sV -sC).

O projeto identificou serviços SSH e HTTP rodando em versões desatualizadas e documentou a análise de risco de cada porta encontrada, incluindo a diferença entre portas fechadas e filtradas por firewall.
